# Movie Recommendation System

A Machine Learning project that recommends similar movies using TF-IDF and Cosine Similarity.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn

## Features

- Load movie dataset
- Vectorize movie genres
- Calculate movie similarity
- Recommend similar movies

## Sample Output

Enter Movie Name:

Toy

Recommended Movies:

- Toy Story (1995)
- Toy Story 2 (1999)
- Antz (1998)
- Monsters, Inc. (2001)
- Finding Nemo (2003)
